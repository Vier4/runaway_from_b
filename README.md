# Runaway from B · Побег от Бронислава

A first-person stealth game that runs in the browser. Bronislav is a blogger who has locked you in his village house to film a video. Find the keys, avoid being seen, and escape.

Браузерная стелс-игра от первого лица: блогер Бронислав запер тебя у себя дома, чтобы снять ролик. Найди ключи, не попадись ему на глаза и сбеги.

## How to play

Open `index.html` in a modern browser (Chrome, Edge, Safari, Firefox). Everything is in that one file; Three.js loads from a CDN, so an internet connection is needed.

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move | WASD / arrows | Left stick |
| Look | Mouse (click the screen first) | Right stick |
| Run | Shift | RT / press left stick |
| Crouch | C | B |
| Use / pick up | E | A |
| Mute | M | — |

There is also an on-screen joystick (toggle it in the main menu).

## Modes

- **Практика** — Bronislav can't see you.
- **Лёгкий** — 3 attempts.
- **Сложный** — 1 attempt.

## Endings

There are 7 endings. Unlocking all of them opens the admin panel with cheats: invisibility, flying, object spawning and more.

## Tech

Plain HTML, CSS and JavaScript with [Three.js r128](https://threejs.org/). All models and textures are generated in code; there are no asset files.
